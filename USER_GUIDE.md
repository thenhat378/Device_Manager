# User Guide: Device Management System

Welcome to the Device Management System. This guide will help you understand how to navigate and use the application based on your assigned role and responsibilities.

---

## 1. User Roles

The system supports two main roles:

*   **Administrator (Admin)**: Full access to all modules, including user management, system configuration, and data exports.
*   **Standard User**: Access to core operational features such as managing devices, logging maintenance, and viewing analytics.

---

## 2. Core Functions

### 📦 Devices Module
*   **View Devices**: See a complete list of devices with their current status (Active, Maintenance Needed, Damaged, Decommissioned).
*   **Add/Edit Devices**: Manage device inventory, update location details, and change status.
*   **QR Generation**: Generate and print tracking labels for individual devices or batches.
*   **QR Scanning**: Use the scanner interface to quickly check or update device status.

### 🛠 Maintenance Module
*   **Log Maintenance**: Record inspection results, part replacements, or report incidents for any device.
*   **Track History**: View the complete maintenance timeline for specific devices.
*   **Export Data**: Click the "Excel" button to export maintenance history (inspections, replacements, incidents) to an Excel file for reporting.

### 🔄 Transfers Module
*   **Manage Transfers**: Track device movements between different locations or departments.

### 📊 Analytics Module
*   **View Dashboards**: Monitor overall system health, maintenance statistics, and damaged device counts across different locations (e.g., Lecture Halls).

### ⚙️ Admin & Settings (Admin Only)
*   **User Management**: Add or remove users and manage their access levels.
*   **N8n Workflow Hub**: Configure automated triggers and workflows to streamline operations.

---

## 3. Frequently Asked Questions

**Q: How do I export maintenance logs?**
A: Navigate to the **Maintenance** tab, optionally filter by a specific device serial number, and click the green **"Excel"** button to download the formatted report.

**Q: What do the status colors mean?**
A:
*   🟢 **Active**: Fully operational.
*   🟡 **Maintenance Needed**: Scheduled for check-up or repair.
*   🔴 **Damaged**: Needs repair or decommissioning.
